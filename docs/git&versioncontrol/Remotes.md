# Remote Repositories

A remote repository is a version of the project hosted elsewhere (e.g., a central server).

Remotes enable collaboration.

Common hosting platforms:
- GitHub
- GitLab
- Bitbucket

Remote tracking branches reflect the state of remote repositories.

Synchronization involves:
- Fetching (downloading changes)
- Pulling (fetch + merge)
- Pushing (uploading commits)
