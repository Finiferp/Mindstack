# Git Workflows

Workflows define how teams organize branches and releases.

Common workflows:

## Centralized Workflow
Single main branch.

## Feature Branch Workflow
Each feature developed in separate branch.

## Git Flow
Defined branches:
- Main
- Develop
- Feature
- Release
- Hotfix

## Forking Workflow
Common in open-source projects.

Workflow choice depends on:
- Team size
- Release frequency
- Deployment strategy
