# Rebasing and History Management

Rebasing moves commits from one base to another.

Instead of merging histories, rebasing rewrites commit history.

## Merge vs Rebase

Merge:
- Preserves historical context
- Shows branch structure

Rebase:
- Creates linear history
- Cleaner timeline
- Rewrites commit hashes

Rebasing should not be used on shared public branches because it alters history.
